TriboContact User Manual & Physics Reference

Contact mechanics for spherical indentation and sliding on single-layer and N-layer coated substrates

TriboContact is a standalone contact-mechanics workbench for analyzing ball-on-flat tribotests on single-layer and multilayer coated specimens. Given a spherical indenter, normal load, optional sliding friction coefficient, and an arbitrary stack of N coating layers over a substrate, TriboContact always evaluates two classical Hertz baselines together with two complementary coated solvers: a fast semi-analytical Layered Elastic solver (Engine 1) and an automated CalculiX Axisymmetric Elastic-Plastic FEM solver (Engine 2).

Solver Architecture

Solver / Baseline Method Assumptions & Strengths Key Outputs
Hertz Substrate Closed-form analytical sphere-on-half-space Ignores all coatings; lower/upper bound for very thin coatings (h / a « 1) a, δ, p0, pmean, centerline σvM
Hertz Top Film Closed-form analytical using top coating E1, ν1 Semi-infinite top coating limit; bound for very thick coatings (h / a » 1) a, δ, p0, pmean, centerline σvM
Engine 1: Layered Elastic Hankel Stiffness Matrix Method (SMM) + Polonsky-Keer CG + Hamilton sliding Exact N-layer linear elasticity in milliseconds; resolves interface stress jumps and 3D sliding tensile peaks p(r), 2D (σrr, σθθ, σzz, τrz, σvM), zk−/zk+ interfaces, yield ratio
Engine 2: CalculiX FEM 2D axisymmetric graded quad mesh (CAX4) with NLGEOM and J2 plasticity Captures substrate/film yielding, strain hardening, contact spreading, plastic bending of hard films, and unloading Plastic p(r), PEEQ, residual depth hr, unsmoothed per-region interface stresses
Consistent Internal Solver Units
Both solvers use an exact coherent unit triad where 1 GPa · μm2 = 1 mN: lengths in μm, stress and elastic moduli in GPa, and forces in mN. User inputs in mm, nm, N, or MPa are converted automatically at the interface boundary.

Quick Start

  1. Select or configure a case — Open File > Examples (such as TiN 2 μm on 304 Steel or DLC 1.5 μm on Glass) or set ball diameter, load, friction, coating layers, and substrate in the left input panel.
  2. Verify CalculiX (for Engine 2) — Check the status bar. If CalculiX is not yet installed, click Setup CalculiX on the toolbar or run TriboContactCLI.exe setup-ccx.
  3. Run the simulation — Click Run Solve or press F5. Engine 1 runs first, and Engine 2 automatically runs in a background thread with live log streaming.
  4. Inspect contact, interface, and yield data — Review the summary comparison table, yield warning banner, dual-sided interface table (zk− and zk+), and interactive plot tabs.
