GUI & CLI Guide

Input setup, background execution, visual diagnostics, command-line automation, and data exports

Desktop GUI Panels

Left Input Panel

  • Indenter Ball — Select a ball preset (such as Si3N4, Al2O3, WC-Co, 100Cr6 Steel), enter size in Diameter (mm), Radius (mm), or Radius (μm) (live unit conversion when switching), edit E and ν inline, or enable Rigid Ball.
  • Load & Friction — Specify normal load FN in N or mN, plus friction coefficient μ ≥ 0. Setting μ > 0 enables the 3D sliding harmonic field in Engine 1.
  • Coating Stack (Top to Bottom) — Build 0, 1, or N coating layers using Add..., Edit..., Remove, Up, and Down. Thickness accepts μm or nm; optional σy, Et, and hardness H (with Estimate σy = H / 2.8) enable plasticity and yield-ratio checks.
  • Substrate — Choose a substrate preset or enter custom elastic and plastic constants.
  • Solver Settings — Choose Both (Elastic + FEM), Layered Elastic (Engine 1), or CalculiX FEM (Engine 2); FEM mesh preset (Coarse, Standard, Fine); element type (CAX4 or CAX4I/CAX4R); Engine 1 ring count; and optional FEM unloading step for residual depth hr.

Right Results Area

  • Yield Status Banner — Highlights elastic safety vs. yield onset warning (max σvM/σy > 0.95 or nonzero PEEQ).
  • Solver Summary Table — Compares Hertz Substrate, Hertz Top Film, Layered Elastic, and CalculiX FEM side by side on a, δ, hr, pmax, pmean, max σvM/σy, and max PEEQ.
  • Interface Discontinuities Table — Lists both sides (zk− above and zk+ below) at every film-film and film-substrate boundary without cross-interface averaging.
  • Plot Tabs:
    1. Contact Pressure p(r) — Interactive chart overlaying all active solvers and baselines.
    2. 2D Stress Heatmap — Renders σvM, σrr, τrz, PEEQ (FEM), and sliding σxx (y = 0 plane for μ > 0) with interface dashed lines.
    3. Centerline Depth Profile — Inverted depth axis plotting σvM(0, z) and σrr(0, z) with sharp step jumps across interfaces.
    4. Load Sweep — Multi-load parametric sweep plotting pmax, pmean, a, and max σvM/σy vs. FN.
    5. FEM Mesh Preview — Color-coded conforming quad mesh with toggleable zoom into the fine contact zone.
    6. Solver Log — Live CalculiX console output, bracket iteration load error, and timing.
Keyboard Shortcuts
Press F5 to start a simulation solve, click Cancel at any time to terminate a running CalculiX job cleanly, and press F1 to open this HTML manual.

Built-In Example Cases

Example File Stack & Indenter Default Conditions Physical Regime
examples\tin_on_steel.json 2 μm TiN on 304 Steel, Si3N4 6 mm 5 N, μ = 0 Hard brittle film over ductile yielding steel substrate (flexural stress reduction vs. elastic)
examples\dlc_on_glass.json 1.5 μm DLC on Glass, Si3N4 6 mm 2 N, μ = 0.20 Sliding coated elastic contact generating trailing-edge surface tensile stress
examples\hard_film_on_polymer.json 1 μm SiC on PMMA, 100Cr6 6 mm 200 mN, μ = 0 Extreme modulus mismatch (Ef / Es ≈ 128) causing strong plate bending on compliant polymer

Command-Line Interface (TriboContactCLI.exe)

All executables (TriboContact.exe, TriboContactCLI.exe, and TriboContactTests.exe) reside in out\bin\:

out\bin\TriboContactCLI.exe setup-ccx [--url <zip_url>]
out\bin\TriboContactCLI.exe validate
out\bin\TriboContactCLI.exe solve examples\tin_on_steel.json --engine both --out-dir my_run --pdf
out\bin\TriboContactCLI.exe sweep examples\dlc_on_glass.json --loads-mn 500,1000,2000,5000 --engine elastic
out\bin\TriboContactCLI.exe gui

Exported Files

  • results.json — Complete case parameters, summary metrics, pressure curves, centerline arrays, 2D stress grids, and dual-sided interface tables.
  • summary.csv, pressure.csv, centerline.csv, interfaces.csv — Tabular ASCII CSV exports ready for Origin, Excel, or Python post-processing.
  • pressure.png, centerline.png, heatmap_*.png, sweep.png (plus optional vector-wrapped .pdf files via --pdf or GUI Export Plots).
