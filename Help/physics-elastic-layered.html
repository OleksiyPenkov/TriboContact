Semi-Analytical Layered Elastic Solver (Engine 1)

Hankel Stiffness Matrix Method (SMM), asymptotic subtraction, Polonsky-Keer CG, interface discontinuities, and 3D sliding friction

1. N-Layer Elastic Stack Model

Engine 1 models an arbitrary stack of N isotropic linear-elastic layers (thickness hk, Young's modulus Ek, Poisson's ratio νk for k = 1, …, N) perfectly bonded to a semi-infinite substrate (Es, νs). Every interface z = zk enforces strict traction and displacement continuity:

ur(zk−) = ur(zk+),   uz(zk−) = uz(zk+),   σzz(zk−) = σzz(zk+),   τrz(zk−) = τrz(zk+)
(1)

In contrast, the in-plane stresses σrr, σθθ, and σvM are discontinuous across every interface whenever moduli or Poisson's ratios differ between adjacent materials.

2. Stiffness Matrix Method (SMM) — Overflow-Free Hankel Formulation

Applying the axisymmetric Hankel transform of order 0 (for normal stress/displacement) and order 1 (for radial components) with radial wavenumber ξ reduces the Navier equations in each layer k to a 2×2 block stiffness relation relating interfacial displacements (Uk, Wk) to interfacial tractions.

Why SMM Instead of the Transfer Matrix Method
The classical Thomson-Haskell Transfer Matrix Method contains growing exponentials exp(+ξhk), which overflow double precision at high wavenumbers or thick stacks. TriboContact uses the Stiffness Matrix Method (SMM) formulated strictly with bounded decaying exponentials Ek = exp(−ξhk) ∈ (0, 1], with a fourth-order Taylor expansion of the denominator for thin layers (ξhk < 10−3) to eliminate catastrophic cancellation.

Recursively assembling each layer upward from the substrate half-space stiffness Ksub yields the exact surface compliance matrix Gcoated(ξ) relating surface tractions (q(ξ), p(ξ)) to surface displacements:

Kbelow(k−1) = K11(k) − K12(k) (K22(k) + Kbelow(k))−1 K21(k),   Gcoated(ξ) = (Kbelow(0))−1
(2)

3. Asymptotic Splitting & Concentric-Ring Influence Matrix

For large wavenumbers ξh1 → ∞, the coated normal compliance approaches the top-layer homogeneous half-space compliance Gzztop(ξ) = 2(1 − ν12) / (E1ξ). Because Gzztop(ξ) decays slowly as 1/ξ, direct numerical Hankel quadrature converges poorly. Engine 1 therefore splits the Green's function analytically:

Gzzcoated(ξ) = Gzztop(ξ)analytical ring kernel + ΔGzz(ξ)exponentially decaying residual
(3)
  • Singular homogeneous part — Integrated analytically over each piecewise-constant concentric pressure ring [rj, rj+1] using complete elliptic integrals of the first and second kind (EllipK, EllipE), with series expansions near the r = rj logarithmic singularity.
  • Smooth coated residual ΔGzz(ξ) — Integrated with 12-point Gauss-Legendre panels up to ξmaxh1 ≥ 25 (plus Filon oscillatory quadrature for very thin films), and added with the elastic indenter compliance 2(1 − νb2) / (Ebξ) when the ball is deformable.

4. Polonsky-Keer Conjugate Gradient (CG) Contact Solver

Discretizing the contact radius domain into M uniform concentric rings gives the influence matrix Dij linking ring pressure pj to normal surface deflection wi = Σj Dij pj. Engine 1 solves the normal contact complementarity problem via the Polonsky-Keer active-set CG iteration:

pi ≥ 0,   gi = wi + hgap(ri) − δ ≥ 0,   pi gi = 0,   Σi Ai pi = FN
(4)

The spherical gap hgap(r) uses r2 / (2R) for small contact angles and exact spherical geometry R − √(R2 − r2) when rmax / R > 0.05. The grid automatically adapts (up to 2 re-grids) so the solved contact radius a occupies roughly 25%–85% of rmax.

5. Dual-Sided Interface Evaluation & 3D Sliding Friction (μ > 0)

Subsurface stress evaluation samples internal layer points plus exact boundary rows above (zk−) and below (zk+) every interface. Interfacial displacement-traction vectors propagate downward cleanly through the already-computed stiffness transfer matrices Tk = −(K22 + Kbelow)−1K21, avoiding overflowing exp(+ξz).

When μ > 0, tangential traction q(r) = μ p(r) acts along +x on the contact patch. Decomposing the surface traction vector into azimuthal mode m = 1 couples two independent linear boundary-value problems:

  • P-SV mode — Uses the 2×2 SMM compliance matrix to capture in-plane and vertical normal/shear response.
  • SH mode — Uses a decoupled 1D scalar stiffness matrix recursion for out-of-plane antiplane shear displacement VSH(ξ).

Consistent with Hamilton (1983) on a homogeneous half-space, sliding induces a strong tensile peak in σxx at the trailing edge (x = −a, y = z = 0) where normal compression vanishes and friction-induced tension peaks:

σxxmax(−a, 0, 0) = p0 [ 1 − 2ν3 + μπ 4 + ν8 ]
(5)
Scope of Engine 1
Engine 1 assumes purely linear elasticity, infinitesimal strains, and uncoupled normal-tangential contact pressure (Goodman's approximation, neglecting Dundurs mismatch β in p(r)). When any layer or substrate reaches σvM / σY > 0.95, switch to or compare with Engine 2 FEM.
